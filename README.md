# YouTube封印タイマー

YouTubeにアクセスすると自動でブロック画面に切り替わり、残り日数が表示されるChrome拡張です。

## 導入方法

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（youtube-seal）を選択する
5. インストール直後に設定画面が自動で開くので、封印日数（デフォルト14日）を決めて開始する
6. **解除コードが1回だけ表示されます。** すぐに見返せない場所に保管してください
   （紙に書いて信頼できる人に預ける、家族に預ける、封筒に入れて封をする等）

以降、youtube.com にアクセスすると自動でブロック画面（残り日数表示）になります。

## 解除の仕組み（意図的に面倒にしています）

- 早期解除には「解除コード」と「48時間のクールダウン」の両方が必要です
- 延長（封印を伸ばす）はいつでも即座に可能です

## 拡張機能自体の無効化について（重要・正直な限界）

ブラウザの拡張機能である以上、`chrome://extensions` から手動で「無効化」「削除」することは
技術的には誰でも（管理者権限があれば）できてしまいます。これはこの方式の限界です。
もっと強い強制力が欲しい場合は、以下のような追加手段を組み合わせることを検討してください。

- **家族・友人にパスワード管理を頼む**：PCの管理者アカウントのパスワードを自分では
  変更できないようにし、他人に握ってもらう
- **OSのペアレンタルコントロール機能**（Windowsのファミリーセーフティ、macOSのスクリーンタイム等）
  を使い、自分以外の管理者アカウントでYouTubeブロックを設定する。この場合、自分のアカウントには
  管理者権限を与えないことがポイントです
- **ルーターレベルでのブロック**：家庭用ルーターの設定でyoutube.comへのアクセスを
  スケジュールブロックする（ブラウザ拡張より解除の手間が増えます）
- **企業向け管理ポリシー（上級者向け）**：Chromeの `ExtensionSettings` 管理者ポリシーを
  レジストリ（Windows）やプロファイル（Mac）で設定すると、指定した拡張機能を
  一般ユーザーが無効化・削除できないようにできます。自分のPCに自分で設定しても
  「解除には別途ポリシーの削除が必要」という一段階が増えるので抑止力になります

一番強力なのは「技術的に完全に阻止する」ことではなく、「解除にかかる手間や
恥ずかしさ（誰かに頼む）を増やして、衝動的な解除を防ぐ」という設計です。
今回のコード＋クールダウンの仕組みもその考え方に基づいています。
